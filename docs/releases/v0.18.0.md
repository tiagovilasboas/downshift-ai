# Release v0.18.0

> **Product maturity: beta.** `v0.18.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

A minor release that takes compaction to much more of what coding agents actually run. Before it, the compactor cut
about 1.6% of one operator's tool output: most outputs were under the 16 KB post-run threshold, wrapped in a shell form
the policy refused, or came from tools no hook compacted. [CHANGELOG](../../CHANGELOG.md#0180---2026-11-17) lists every
change.

## Projected effect

**About 3.5x to 4.5x more tokens cut per month on the same workload**: from about 1.0M tokens (last 30 days,
`downshift stats`, saved bytes / 4) to about 3.5M to 4.5M.

This is a projection, not a measurement. It applies the v0.18.0 rules to one operator's last 30 days of Claude Code
transcripts (69,341 tool results, deduplicated), and it has not been measured after the release. Method, inputs,
assumptions and what it leaves out: [compaction projection](../evidence/compaction-projection-2026-11-17.md).

## What changed

### More output reaches the compactor

- **Post-run cut from 4 KB.** On Claude Code, a result between 4 KB and 16 KB is now cut after the run too, with the
  raw output kept for `downshift retrieve`. `downshift doctor` shows both thresholds.
- **WebFetch and MCP results are compacted.** Large `WebFetch` and `mcp__*` results are cut after the run
  (`updatedToolOutput` / `updatedMCPToolOutput`). Errors and image blocks stay whole. **Read is never cut** under 64 KB.
- **More commands are wrapped before the run.** `;` and `&&` chains, quoted globs (`grep -rn "foo*" .`), binaries
  under known bin directories (`/opt/homebrew/bin/gh`), bare `| head` / `| tail`, and commands up to 2,048 bytes
  (was 512). Arbitrary absolute paths, redirects, substitutions and `||` are still refused.
- **Nine more families compress.** `terraform plan`, `cargo clippy`, `cargo tree`, `docker logs`, `kubectl logs`,
  `composer`, `artisan` / `sail artisan` and `az pipelines`, each with fail-open guards.
- **Read-only `downshift` commands** (`stats`, `discover`, `report`, `doctor`, `version`, `help`, `session`, `models`)
  are compacted like any other allowlisted command.

### New compressors

- **JSON from `gh api` and `curl`**: drops `*_url`, `node_id`, `gravatar_id`, `_links` and long `url` values, and
  folds arrays over 20 items into a count. IDs, names, titles and states stay.
- **`gh pr checks`** as a FAIL / PENDING / SKIP / PASS summary, and **`gh pr diff`** as per-file stats and hunk headers
  above 120 lines.
- **Git lists and `wc`**: `git ls-files`, `ls-tree`, `branch`, `worktree`, `remote` and `wc` over 40 lines keep the
  first 25 lines and a count.
- **Large `git diff`, `git show` and `git status`**: per-file `+add -del` stats and hunk headers above 120 lines;
  `git status` above 30 lines grouped into staged, unstaged and untracked with counts. Conflicts stay raw.

### Measurement

- **`downshift discover --dedup`** counts each tool call once (by `tool_use_id`) and splits coverage into Bash and
  non-Bash, so a resumed session no longer counts the same output twice.
- The MCP `providers` tool returns a smaller payload.

## What you need to do

1. Run `downshift update`, or install v0.18.0 with `install.sh` or the
   [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. Run `downshift setup --yes`; with the Claude Code plugin, also run `claude plugin update downshift@downshift`. Both
   add the new `WebFetch|mcp__.*` PostToolUse matcher. Open a new harness session.
3. Check `downshift doctor`: the compactor line reads `outputs over 16 KB (post-run over 4 KB)`.
4. After a week, compare `downshift stats` and `downshift discover --dedup --since=7d` with the
   [projection](../evidence/compaction-projection-2026-11-17.md#how-to-check-it).
