# Downshift v0.25.0

Release date: 2026-11-28.

This release addresses five live coverage and observability bottlenecks measured on v0.24.x telemetry: multi-line outputs missing an EOF newline now compact cleanly, `--harness=<name>` invocations inside agent PTYs no longer abort compaction on stderr, read-only lock/log files compact from `8 KiB` with verified sub-range read dedup, `doctor` warns when installed plugin commits lag behind the binary, `downshift compact` disambiguates harness inference across `AllHarnessCaps()`, and the read-only pre-run policy expands safely for `git -C`, `git tag`, `git config`, `git grep`, and `docker` reads.

## Highlights

- **Multi-line EOF newline tolerance & explicit-harness PTY mode (`#246`)**: `screenText` in `internal/compressor/colour.go` normalizes multi-line outputs missing only a trailing `\n` (keeping single-line partial chunks raw as `no_final_newline_preserved`, and tightening `reGoTestPass` duration matching so truncated lines fail open); `execwrap.Run` treats explicit `--harness=<name>` calls (wired from `cmd/downshift/exec.go`) as non-interactive so PTY-backed agent runners still hold and compact stderr cleanly.
- **`Read` 8 KiB threshold for lock/log files & verified sub-range dedup (`#245`)**: adds `ReadOnlyFileThreshold = 8 KiB` (`2 KiB` head/tail verbatim with full CCR storage) for explicit read-only artifacts (`*.lock`, `go.sum`, `*.jsonl`, `*.log`, `*.min.js`, `*.min.css`, `*.map`) while leaving `ReadThreshold = 64 KiB` untouched for normal source code; extends session `read_dedup.go` to deduplicate unchanged narrower sub-range reads using per-line hashes (invalidated immediately on any edit).
- **Doctor lagging-commit warning & unambiguous harness inference (`#244`)**: `doctor` (`plugin hooks`) warns when `installed_plugins.json`'s commit lags behind the running binary commit even when hook counts match; `downshift compact` infers the harness from `core.AllHarnessCaps()` (`SessionEnv`/`ShellEnv`) only when exactly one harness matches cleanly.
- **Read-only pre-run policy expansion (`#247`)**: strips leading `-C <dir>` pairs consistently in `policy_readonly.go`, adds guarded read-only support for `FamilyGitTag` (list flags only), `FamilyGitConfig` (get/list only), `FamilyGitGrep`, read-only git inspection subcommands (`describe`, `rev-list`, `merge-base`, `ls-tree`, `show-ref`, etc.), bare `ls`/`find`, `FamilyDockerPS`/`Images`/`Logs`, and `FamilyGlab`, while explicitly blocking `docker exec` and preserving all Codex/Cursor/`promptsSuppressed` invariants.
