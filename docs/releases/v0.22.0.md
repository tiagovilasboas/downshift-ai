# Downshift v0.22.0

> [!NOTE]
> **Product maturity: beta.** Downshift is ready for daily individual use on macOS, Linux, and Windows. Hooks fail open; the Claude Code plugin's compact and balanced modes are verified on real sessions, while full cross-harness production telemetry continues to grow. See [Beta exit criteria](../reference/beta-exit.md).

`v0.22.0` builds on [v0.21.0](v0.21.0.md) to prevent wrapped commands from hanging in non-interactive agent runs, splits telemetry read-outs from log I/O, and replaces implicit `init()` hook registration with explicit startup wiring.

## What changed

- **Compactor execution timeout (`DOWNSHIFT_EXEC_TIMEOUT`, `#219`):** optional Go duration (such as `30s` or `2m`) bounds `downshift compact` child execution, terminates the child process group cleanly (with a `200ms` grace period before `SIGKILL`), flushes buffered output, and exits `124` on timeout. Unset, empty, or invalid values fail open with no timeout.
- **Non-TTY prompt guard (`#219`):** when `stdin` is not a terminal, `downshift compact` injects `GIT_TERMINAL_PROMPT=0` and `GH_PROMPT_DISABLED=1` (unless already set by the caller) so background `git` and `gh` invocations fail fast instead of hanging on interactive prompts.
- **Telemetry readout split & explicit startup wiring (`#218`):** moved pure in-memory analytics and presentation helpers into `internal/telemetry/readout`, leaving `internal/telemetry` focused on schema, direction, and log I/O; replaced production `init()` hook registration in `internal/core`, `internal/quota`, `internal/compressor/learning`, and `cmd/downshift` with explicit `wireRuntime()` startup wiring; and synced [architecture.md](../design/architecture.md) and [gap-tasks.md](../internal/gap-tasks.md).
- **Dependency bumps (`#216`, `#217`):** updated `charm.land/bubbletea/v2` (`2.1.1 -> 2.1.2`) and `actions/setup-go` (`7.0.0 -> 7.1.0`).

## What you need to do

- Update with `downshift update`, `brew upgrade tiagovilasboas/tap/downshift`, or the installers (`install.sh` / `install.ps1`).
- Set `DOWNSHIFT_EXEC_TIMEOUT=2m` (or any Go duration) if you want `downshift compact` to enforce a hard per-command wall-clock limit.
