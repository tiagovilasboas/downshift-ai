# Downshift v0.19.0

> [!NOTE]
> **Product maturity: beta.** Downshift is ready for daily individual use on macOS, Linux, and Windows. Hooks fail open; the Claude Code plugin's compact and balanced modes are verified on real sessions, while full cross-harness production telemetry continues to grow. See [Beta exit criteria](../reference/beta-exit.md).

`v0.19.0` adds quota-unit estimates and skill parity across `stats`, `report`, and the `downshift-agents` pane, shell completions for Bash/Zsh/Fish/PowerShell, a native Windows PowerShell installer with SHA-256 verification, Homebrew tap documentation, and OpenSSF Scorecard / CodeQL / Dependabot automation.

## What changed

- **Quota estimate and skill parity (`#155`):** `downshift stats`, `downshift report` (`--text`, `--json`, and markdown), `downshift session --panel`, and the `downshift-agents` pane compute per-harness unitless quota estimates (`QuotaUnits`, weights small `0.05`, cache read `0.1`, mid `1`, frontier `2`) and expose 30-day `ponytail` skill adoption parity.
- **Shell completions (`#158`):** `downshift completion bash|zsh|fish|powershell` emits completions for every subcommand and top-level flag.
- **Windows installer and Homebrew docs (`#159`):** Added `install.ps1` with SHA-256 verification and documented `brew install tiagovilasboas/tap/downshift`.
- **Open-source & CI posture (`#157`):** Added CodeQL, OpenSSF Scorecard, Dependabot, Dev Container, `SUPPORT.md`, `FUNDING.yml`, and local `actionlint` enforcement in `lefthook.yml`.
- **Documentation & dependencies (`#156`, `#160`):** Highlighted daily workflows across READMEs/guides and bumped `charm.land/lipgloss/v2` to `2.1.1`.

## What you need to do

- Update with `downshift update`, `brew upgrade tiagovilasboas/tap/downshift`, or the shell/PowerShell installer (`install.sh` / `install.ps1`).
- Run `downshift setup --yes` if you want refreshed skills or shell completions (`downshift completion zsh`, etc.).
