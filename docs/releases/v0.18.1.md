# Release v0.18.1

> **Product maturity: beta.** `v0.18.1` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

A patch release that fixes post-run compaction in auto/suppressed modes, `direct` and retrieval token accounting, 6-generation rotated compactor logs, cross-harness `SkillsDir` parity, honest skill telemetry (`ponytail`), `agent-desktop` read-only pre-run classification, and the `web-motion` frontend guidance. [CHANGELOG](../../CHANGELOG.md#0181---2026-11-18) lists every change.

## What changed

- **Post-run compaction in suppressed permission modes and background runs.** Postrun now evaluates full `WouldRewriteEvent` against the parsed hook payload instead of command-only `WouldRewrite`, so commands skipped as `not_read_only` in PreToolUse still compact and record in PostToolUse (#149).
- **Accurate token accounting and log retention.** Direct compactor calls classify by `Entry == "direct"`, secondary CCR `KeptIDs` and routing tokens stay intact across postrun and retrieval matching, and rotated compactor logs retain 6 generations (`.1`..`.6`) across Windows and Unix (#149, #150).
- **`agent-desktop` and cross-harness parity.** Added `agent-desktop` (`snapshot`/`find`) to read-only families, wired `antigravity` `SessionIdentifier` and `kiro.HandlePostToolUse`, and set `SkillsDir` for Cursor, OpenCode and Antigravity so `downshift setup --yes` installs `ponytail` and Downshift skills everywhere (#149, #150).
- **Skill adoption telemetry (`ponytail`).** Added `OutcomeSkillUsed` with strict allowlisting, Claude Code `Skill` PostToolUse tracking, and `Adoption.Skills` display in `downshift stats` (#149).
- **Compositor-friendly `web-motion` skill and `coder-front` guidance.** Added plugin-only `skills/web-motion/SKILL.md`, moved `agents/coder-front.md` to DOM + WAAPI/CSS motion defaults, and updated `internal/playbook/assets/frontend.md` (#152).

## What you need to do

1. Run `downshift update`, or install v0.18.1 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. Run `downshift setup --yes` (and `claude plugin update downshift@downshift` if using the plugin) so installed skills and plugin files match the new release, then open a new harness session.
