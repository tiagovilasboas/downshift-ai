# Downshift v0.24.0

Release date: 2026-11-26.

This release raises pre-run rewrite and post-run compaction coverage across real-world agent sessions: quote-aware chain splitting up to 32 segments, `git -C` support, tight and two-stage pipes (`cmd|grep|tail`), safe read-only families (`wc`, `find`, `grep`, `rg`, `cat`/`head`/`tail`/`sed -n`/`jq`), targeted quoted rules, generic MCP payload pruning, `FamilyNone` failure fallback, post-run stderr/read-dedup improvements, and live version + cached update notices in the `downshift-agents` band and pane.

## Highlights

- **Quote-aware chains, safe read-only families & targeted quoted rules (`#235`)**: `splitChain` respects `'...'`, `"..."`, and escapes, raising `maxChainSegments` from `8` to `32`; `ReadOnly` allows safe `FamilyWc`, `FamilyFind`, `FamilyGrep`, `FamilyRg`, `FamilyFileRead`, and non-mutating `FamilyGitFetch`; and `quoted_rules.go` scopes quoted `Bash(...)` deny/ask rules to matching command binaries instead of blocking all quoted commands globally.
- **`git -C`, tight/2-stage pipes & `cat -n` / `sed -n 'A,$p'` (`#238`)**: allows repeatable safe `git -C <dir>` (while keeping `-c`/`--config` refused), splits tight unquoted `|` and `2>/dev/null | filter`, validates two-stage read-only pipe tails (`| grep | tail`, `| sort | uniq -c`), and adds `cat -n` and `sed -n 'A,$p'` to `policy_read.go`.
- **Generic MCP pruner & unnumbered `search_cap` (`#233`)**: adds `pruneGenericMCP` for large JSON/object MCP payloads and supports unnumbered `path:text` match lines in `search_cap.go`.
- **Post-run stderr, scaled verbose fallback, piped filters & read dedup (`#234`)**: routes `git fetch`/`pull`/`push` and test-report stderr through family compressors when stdout is empty, adds `BalanceBytesScaled` fallback for `WebFetch`/MCP verbose payloads, widens safe `grep`/`sort`/`uniq`/`cat` pipe stages, and lowers the repeat-read dedup floor to `512` B.
- **`FamilyNone` non-zero exit fallback (`#239`)**: routes unclassified/compound failing runs over the balanced threshold into `BalanceFailed` when CCR stores the raw output, preserving `keep == nil` and `anti_loop_bypass` guards.
- **Discover telemetry fixes (`#232`)**: eliminates zero-timestamp leaks in `missedsavings` scans and classifies `run_in_background` Bash calls as `KindSkipped` (`background`).
- **Running version & update notice in `downshift-agents` (`#236`, `#237`)**: `session --panel` emits the build `version` and cache-only `latest` / `update_available` fields from `latest_release.json` (zero network calls); the band renders `Downshift - vX.Y.Z` (with `↑ vY.Z.W` in `WARN` when outdated), and the pane and `/ds-agents summary` show a one-line update notice.
