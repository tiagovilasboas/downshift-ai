# Downshift v0.20.0

> [!NOTE]
> **Product maturity: beta.** Downshift is ready for daily individual use on macOS, Linux, and Windows. Hooks fail open; the Claude Code plugin's compact and balanced modes are verified on real sessions, while full cross-harness production telemetry continues to grow. See [Beta exit criteria](../reference/beta-exit.md).

`v0.20.0` is a compaction release. Downshift now cuts much more of the output it used to pass through whole, and every lossy cut stays retrievable with `downshift retrieve`.

## How much more

On an offline replay of 30 days of real Claude Code sessions (26,452 shell outputs over 1 KB, 28.7M raw tokens), the post-run cut rose from **27.4% to 32.2%** (residual 20.9M → 19.5M tokens). The replay does not include session dedup or the pre-run chain wrapping, so live savings run higher. These are output tokens only, not total session tokens.

## What changed

- **Unclassified output (`#184`, `#190`, `#196`–`#198`, `#202`, `#203`):** a lossless pass (ANSI, progress, repeats), shapes for grep rows, diffs and path lists, and a byte-budget cut once CCR stored the raw text. Shapes run inside an agent's own `head`/`tail` limit; the byte cut does not.
- **rtk-style passes (`#207`):** long-line cap, near-repeat folding, shell JSON pruning, one context line per side for diffs over 8 KiB. Error lines are never cut.
- **Family fallback cut (`#206`):** an unrecognized `go test -v` or a failing `make` gets the balanced cut instead of passing through; failed runs keep every failure line.
- **Piped and chained commands (`#204`, `#205`):** `cmd | tail -N` reaches its family compressor after the run; each allowlisted segment of a chain is wrapped before it.
- **Session dedup (`#194`, `#201`):** repeated reads and outputs become a pointer to the first copy.
- **New families and pipes (`#167`–`#172`, `#195`):** `swift test`, `ctest`, `mix test`, `git branch`/`remote`/`ls-files`, `ls`, safe redirects and text pipes, MCP JSON and Grep/Glob results.
- **Measurement (`#175`–`#183`, `#186`, `#187`, `#191`, `#199`, `#200`):** the `other` family broken down by program and line bucket, outcomes by spawn origin, recorded subagent API-error and interrupt ends.

## What you need to do

- Update with `downshift update`, `brew upgrade tiagovilasboas/tap/downshift`, or the installers (`install.sh` / `install.ps1`).
- Nothing else: the new passes are on by default. `DOWNSHIFT_BALANCED=0` turns the lossy cuts off; `DOWNSHIFT_CCR=0` turns off the store, and with it every lossy cut.
