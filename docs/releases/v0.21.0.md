# Downshift v0.21.0

> [!NOTE]
> **Product maturity: beta.** Downshift is ready for daily individual use on macOS, Linux, and Windows. Hooks fail open; the Claude Code plugin's compact and balanced modes are verified on real sessions, while full cross-harness production telemetry continues to grow. See [Beta exit criteria](../reference/beta-exit.md).

`v0.21.0` builds on [v0.20.1](v0.20.1.md) to protect agents from retry loops on repeated failures, expose prompt-cache health and CCR recovery share in local reports, and ship a reproducible proof benchmark alongside a paired live A/B kit.

## What changed

- **Active anti-loop bypass (`#211`):** after two consecutive identical failing CCR digests in the same session within 30 minutes, Downshift steps aside from lossy compaction and delivers the raw failure output verbatim (`anti_loop_bypass`), clearing the streak once the command passes.
- **Prompt-cache health & CCR retrieval telemetry (`#212`):** `downshift report` and `downshift stats` track `cache_write` and uncached `input` tokens alongside `cache_read` to display per-harness `cache hit %`, and report CCR retrieval share (`% of cut`) so you can verify compression is not hiding needed signal.
- **1-command offline proof benchmark & public A/B kit (`#213`):** `make bench-proof` verifies four invariants offline in seconds (89.2% byte cut across the 4 bundled balanced fixtures — `324,913 -> 35,113` bytes — with 4/4 byte-exact CCR recovery, `anti_loop_bypass` on consecutive failures, prompt-cache prefix invariance on main-session and spawn payloads, and user-owned `.downshift/policy.json` risk floors). `scripts/bench-ab/` and [Reproducing the benchmarks](../guides/reproduce-benchmark.md) add a paired live A/B harness for Claude Code and Codex.
- **Prompt-cache safety & vendor-neutral positioning docs (`#214`):** added [Prompt-cache safety](../features/prompt-cache-safety.md) and updated [Compaction](../features/compaction.md), `README.md`, and `docs/pt-br/README.md`.

## What you need to do

- Update with `downshift update`, `brew upgrade tiagovilasboas/tap/downshift`, or the installers (`install.sh` / `install.ps1`).
- No configuration changes required (`DOWNSHIFT_BALANCED=0` and `DOWNSHIFT_CCR=0` behavior is unchanged).
