# Release v0.17.2

> **Product maturity: beta.** `v0.17.2` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

A patch release that fixes a false OK in `downshift doctor` and keeps hooks fast as the event log grows. [CHANGELOG](../../CHANGELOG.md#0172---2026-11-16) lists every change.

## What changed

- **`doctor` no longer reports a hook as working when it never fired.** The `last hook event` check now counts only events the hook wrote; a `git` or `mcp` event for the same harness no longer passes it.
- **`doctor` reads the event log for OpenCode** and any other bridge harness, so the completion and `rewrite honored` checks run there too.
- **Hooks stay fast on a large event log.** Plain tool calls skip the log read, and the rest read only its last 4 MiB.
- **Less text in every session.** The MCP instructions, the largest tool descriptions, the SessionStart context and the longest skill descriptions are shorter; every trigger phrase is kept.

## What you need to do

1. Run `downshift update`, or install v0.17.2 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. Run `downshift setup --yes` so the installed skills and plugin match the binary, then open a new harness session.
