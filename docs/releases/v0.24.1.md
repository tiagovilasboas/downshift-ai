# Downshift v0.24.1

Release date: 2026-11-26.

Patch release following v0.24.0 with background update-notice cache refresh and safer pre-run redirect/chain handling:

- **Detached `latest_release.json` cache refresh (`#241`)**: `downshift session --panel` triggers a throttled, non-blocking detached background refresh (`downshift doctor --refresh-latest-cache`, 1 h attempt cooldown, suppressed under `DOWNSHIFT_NO_NETWORK=1`) when `latest_release.json` is missing or expired, keeping the `↑ vX.Y.Z` update notice in the `downshift-agents` band current without running `doctor --check-latest` manually.
- **Tight stderr-redirect pipes, safe `/dev/null` chain segments & `|| :` (`#242`)**: `policy_redirect.go` allows tight `|` after `2>&1` and `2>/dev/null` (`cmd 2>&1|tail -15`), `policy_chain.go` keeps non-guarded segments with trailing `>/dev/null`, `2>/dev/null`, or `&>/dev/null`, and `policy_quoted.go` supports `|| :` alongside `|| true`.
