# Downshift v0.20.1

> [!NOTE]
> **Product maturity: beta.** Downshift is ready for daily individual use on macOS, Linux, and Windows. Hooks fail open; the Claude Code plugin's compact and balanced modes are verified on real sessions, while full cross-harness production telemetry continues to grow. See [Beta exit criteria](../reference/beta-exit.md).

`v0.20.1` is a patch release on top of [v0.20.0](v0.20.0.md) that removes a large slice allocation in prompt classification.

## What changed

- **Zero-allocation prompt word count (`#209`):** `internal/classify` now counts words with a streaming pass (`countWords`) instead of `len(strings.Fields(prompt))`, avoiding a ~130k-element `[]string` allocation on 900 KB prompts and keeping `TestClassify900KBUnder500ms` well below the 1s CI budget.

## What you need to do

- Update with `downshift update`, `brew upgrade tiagovilasboas/tap/downshift`, or the installers (`install.sh` / `install.ps1`).
- No configuration changes needed.
